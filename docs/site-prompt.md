# COMPLETE-ME browser demo brief

Show the same completion example in Bash, fish, and zsh side by side. Within each shell,
compare default completions with COMPLETE-ME enabled. Show the keystrokes explicitly, including
a second Tab when it is needed to list the choices. Use recordings from real shell sessions.

Keep the examples available immediately. Let visitors replay keystrokes while keeping the
three shells synchronized. Include examples for tmux, a Python command with argparse options,
directory completion, the calculator, and the Alt+J snippet picker.

Use plain HTML, CSS, and JavaScript. Keep the guide and press kit readable without
scripting, and use the repository README and completion guide for technical claims.
